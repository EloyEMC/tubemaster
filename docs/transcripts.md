# Public transcripts

The default transcript provider remains `youtube-captions` and requires Google OAuth. To request a public video's captions explicitly, send `provider: "yt-dlp"` to `/api/video-metadata/transcript` with a video ID (the API still requires an authenticated session), or run `transcript --videoId <11-character-id> --provider yt-dlp` in the CLI. `YOUTUBE_TRANSCRIPT_PROVIDER=yt-dlp` selects it as the process default. There is no automatic fallback between providers; unsupported names return `unsupported`.

Install the `yt-dlp` executable separately and make it available on `PATH` (for example, follow the installation instructions at https://github.com/yt-dlp/yt-dlp#installation). The public provider tries manual captions first, then automatic captions, in English by default. Missing executables, timeouts and extraction failures produce sanitized unavailable diagnostics; no Google OAuth token is passed to the subprocess. Public availability varies by video, region, and YouTube changes. Check YouTube's terms and applicable privacy obligations before using this provider. Public acquisition may expose the server's IP address and video ID to YouTube; do not use it as a privacy or access-control bypass.
